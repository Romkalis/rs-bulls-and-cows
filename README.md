# Bulls and Cows

Учебный проект для задания [Rolling Scopes School — Bulls and Cows](https://github.com/rolling-scopes-school/tasks/blob/master/fullstack-engineering/tasks/bulls-and-cows/README.md).

## О проекте

Bulls and Cows — игра, в которой нужно угадать секретное число из неповторяющихся цифр. После каждой попытки игрок получает подсказку:

- **bulls** — цифры угаданы и стоят на правильных местах;
- **cows** — цифры угаданы, но стоят на других местах.

Секрет генерируется на клиенте. Ограничения на число попыток нет: учитываются количество попыток и затраченное время. После победы результат попадает в таблицу лучших результатов, которая сохраняется в `localStorage`; сначала сравнивается число попыток, затем время.

## Требования задания

- Вся логика и пользовательский интерфейс пишутся на TypeScript.
- Игровая логика реализуется чистыми функциями, без классов и зависимости от DOM.
- Разметка генерируется кодом: `body` в `index.html` остаётся пустым, кроме подключения скрипта. Динамический контент не вставляется через `innerHTML` или `insertAdjacentHTML`.
- Обязательные функции:
  - `generateSecret(length, base, random)` — генерирует секрет из уникальных цифр, принимая источник случайности параметром;
  - `evaluateGuess(secret, guess)` — возвращает количество `bulls` и `cows`, используя методы массивов;
  - `isValidGuess(guess, length, base)` — проверяет длину, допустимые цифры и отсутствие повторов;
  - `createDigitValidator(base)` — возвращает предикат для проверки цифры; для hex регистр не важен;
  - `countPossibleSecrets(length, base)` — рекурсивно считает количество возможных секретов и мемоизирует результат.
- Состояние и история попыток обновляются иммутабельно.
- До начала раунда можно выбрать длину от 2 до 6 и систему счисления: bin, oct, dec или hex. Для bin доступна только длина 2. После начала настройки блокируются.
- История показывает попытки и их результаты. Повторная попытка не должна создавать дубликат.
- После угадывания секрета игра завершается, показывая число попыток и затраченное время. Новая игра открывает настройки без перезагрузки страницы.
- Настроены ESLint, Prettier, Husky и тестовый раннер (Jest или Vitest). В `package.json` предусмотрены скрипты `lint`, `format` и `test`.
- Бэкенд, внешние API и сторонние библиотеки для игровой логики не используются.

## Тестирование и коммиты

Работа над каждой обязательной функцией ведётся по TDD: сначала отдельный коммит с падающими тестами, затем отдельный коммит с реализацией, проходящей эти тесты. Тесты должны быть детерминированными и соответствовать принципам FIRST. Хук `pre-commit` запускает `lint-staged`, а `pre-push` — `npm test`.

## Документация

В `DESIGN.md` описываются структуры данных, алгоритмы `evaluateGuess` и `countPossibleSecrets`, оценка Big O обязательных функций и применённые принципы чистого кода с указанием конкретных файлов и функций.

## Сдача задания

Работа выполняется в ветке `bulls-and-cows` от `main`. Приложение необходимо задеплоить, открыть Pull Request в `main` без слияния и отправить его ссылку через RS App → **Cross-Check: Submit**. В описании Pull Request указываются ссылка на деплой, подтверждение порядка TDD-коммитов, ссылка на `DESIGN.md` и результаты ручной проверки поведения приложения.
