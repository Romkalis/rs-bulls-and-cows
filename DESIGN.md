# DESIGN

## Архитектура

Приложение разделено на чистое ядро и оболочку.

| Слой     | Файлы                                                                        | Что внутри                                                                           |
| -------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Ядро     | `src/core/game.ts`, `src/core/state.ts`, `src/core/records.ts`, `src/utils/` | Правила игры, состояние, рекорды. Нет DOM, `Math.random`, `Date.now`, `localStorage` |
| Оболочка | `src/main.ts`, `src/view/`                                                   | DOM, события, время, случайность, хранилище                                          |

Зависимости направлены только внутрь: `view` и `main` импортируют ядро, ядро ничего не знает о браузере. Случайность и время передаются в ядро параметрами (`generateSecret(length, base, random)`, `startGame(settings, secret, now)`, `applyGuess(state, guess, now)`), поэтому все тесты детерминированы.

## Структуры данных

Все типы описаны в `src/types/core.type.ts`.

- **Секрет и догадка — строки** (`'0123'`, `'af3'`). Строка сохраняет ведущий ноль, который потерялся бы в `number`, и подходит для hex. Регистр приводится к нижнему функцией `normalize` (`src/utils/normalize.ts`).
- **`Base = 2 | 8 | 10 | 16`** — объединение литералов. Недопустимое основание не скомпилируется.
- **`Score = { bulls, cows }`** — результат одной попытки.
- **`GameState`** — неизменяемый объект: `settings`, `secret`, `history: readonly Attempt[]`, `status: 'playing' | 'won'`, `startedAt`, `finishedAt`. Каждый ход создаёт новый объект через spread.
- **`GameRecord = { attempts, time, settings }`** — запись в таблице рекордов, список хранится в `localStorage` в виде JSON.
- **`Set`** — для проверки уникальности цифр (`isValidGuess`) и поиска общих цифр (`evaluateGuess`) за O(1) на элемент.
- **`Map`** — кэш в `memoize`, ключ равен `JSON.stringify(args)`.
- **`Screen`** (`src/main.ts`) — размеченное объединение `{ kind: 'settings' } | { kind: 'game' }`, описывает текущий экран.

## Алгоритмы

### `evaluateGuess(secret, guess)`

1. Обе строки нормализуются в массивы символов в нижнем регистре.
2. **Быки** — символы догадки, совпадающие с секретом на той же позиции: `guess.filter((ch, i) => ch === secret[i]).length`.
3. **Общие цифры** — символы догадки, которые есть в секрете: `guess.filter((ch) => secretSet.has(ch)).length`.
4. **Коровы = общие − быки.**

Формула верна, потому что цифры уникальны и в секрете (`generateSecret`), и в догадке (проверяет `isValidGuess` до вызова). Пример: секрет `1234`, догадка `1543`: быки 1 (`1`), общие 3 (`1`, `4`, `3`), коровы 2.

### `countPossibleSecrets(length, base)`

Число секретов — это число размещений без повторений: на первую позицию подходит `base` цифр, на вторую `base − 1` и так далее.

```
count(0, base)      = 1
count(length, base) = base · count(length − 1, base − 1)
```

Если цифр не хватает, множитель доходит до 0 и результат сам становится нулём: `count(3, 2) = 2 · 1 · 0 = 0`.

Функция обёрнута в `memoize`, а рекурсивный вызов идёт к уже мемоизированной версии, поэтому в кэш попадают и промежуточные значения.

## Сложность

`n` — длина секрета (2–6), `b` — основание (2–16).

| Функция                                | Время                             | Память   | Пояснение                                                                                 |
| -------------------------------------- | --------------------------------- | -------- | ----------------------------------------------------------------------------------------- |
| `createDigitValidator(base)`           | O(b) создание, O(b) вызов         | O(b)     | `slice` алфавита один раз, затем `includes` по строке длины `b`                           |
| `isValidGuess(guess, length, base)`    | O(n · b)                          | O(n)     | `every` с валидатором на каждый символ, `Set` из `n` символов                             |
| `evaluateGuess(secret, guess)`         | O(n)                              | O(n)     | Два `filter` и `Set`, проверка `has` за O(1)                                              |
| `generateSecret(length, base, random)` | O(n² · b)                         | O(n + b) | `n` шагов рекурсии, на каждом `filter` по `b` цифрам с `includes` по секрету длины до `n` |
| `countPossibleSecrets(length, base)`   | O(n) первый вызов, O(1) повторный | O(n)     | Глубина рекурсии `n`, результат берётся из `Map`                                          |

При заданных ограничениях (n ≤ 6, b ≤ 16) все функции выполняются за десятки операций.

## Принципы чистого кода

- **Чистые функции.** `createDigitValidator`, `isValidGuess`, `evaluateGuess`, `countPossibleSecrets` (`src/core/game.ts`), `startGame`, `applyGuess` (`src/core/state.ts`), `compareRecords`, `addRecord` (`src/core/records.ts`) зависят только от аргументов и не имеют побочных эффектов. `generateSecret` чиста, когда передан `random`; `Math.random` используется только как значение по умолчанию.
- **Внедрение зависимостей.** Случайность (`random`) и время (`now`) приходят параметрами, поэтому `src/main.ts` — единственное место, где вызываются `Math.random` и `Date.now`.
- **Иммутабельность.** `applyGuess` возвращает новый объект (`{ ...state, history: [...state.history, attempt] }`); `addRecord` сортирует копию (`[...records, record].sort(...)`); `generateSecret` выбирает цифры через `filter`, а не `splice`. Массивы в типах помечены `readonly`.
- **Функции высшего порядка и замыкания.** `createDigitValidator` возвращает предикат (каррирование); `memoize` (`src/utils/memoize.ts`) принимает функцию и возвращает её версию с кэшем, скрытым в замыкании.
- **Рекурсия.** `generateSecret` (внутренняя `addDigit`) и `countPossibleSecrets`.
- **Методы массивов вместо циклов.** `filter`, `every`, `some`, `map`, `slice` — циклов `for` в ядре нет.
- **Единственная ответственность.** Правила — `game.ts`, переходы состояния — `state.ts`, рекорды — `records.ts`, хранилище — `view/storage.ts`, создание элементов — `view/dom.ts`, каждый экран — свой файл в `view/`.
- **Защита на входе.** `isValidGuess` отсекает неверные догадки до `evaluateGuess`; `generateSecret` бросает `RangeError`, если `length > base`; `loadRecords` перехватывает испорченный JSON.
- **Безопасный DOM.** Разметка создаётся хелпером `el` через `createElement` и `append`, текст попадает в документ только как текстовые узлы; `innerHTML` не используется.
- **Говорящие имена и константы.** `DIGITS`, `MAX_RECORDS`, `STORAGE_KEY` вместо магических значений.

## Тестирование

Тесты лежат рядом с кодом (`*.test.ts`), используется Vitest. Каждая обязательная функция сделана по TDD: сначала коммит `test:` с падающими тестами на заглушке, затем коммит `feat:` с реализацией. Тесты соответствуют FIRST: выполняются за миллисекунды, не зависят друг от друга, детерминированы (случайность подменяется функциями `() => 0` и `sequence([...])`), сами проверяют результат и написаны до кода.
